## [0.1.0] - 2026-11-22

### Added

- Check the managed apps for new versions on GitHub Releases (manual launch and button only).
- Download, verify (SHA-256, package, version, signature) and install updates through the system installer.
- The updater updates itself.
- Hentai Reader is shown and checked only while it is installed; while it is absent there is no row and no network request about it.
